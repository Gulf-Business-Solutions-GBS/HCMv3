# HCMv3.ReportDesigner

A tiny standalone ASP.NET Core MVC app that hosts the real Stimulsoft Report Designer
(their official HTML5/JS drag-and-drop editor) so you can visually open and inspect the
`.mrt` reports produced by the DevExpress-to-Stimulsoft migration pipeline at
`aspnet-core/tools/HCMv3.ReportMigrator/`.

This is a **local, internal, dev-only verification tool**. It is not part of the HCMv3
product and is never meant to be deployed. It has no authentication.

## What it does

- Opens directly to the Stimulsoft Report Designer with the verified, working
  `rptPayslipEn.HCMv3.mrt` payslip report loaded (a copy is bundled under `Reports/`,
  the original in `HCMv3.ReportMigrator` is untouched).
- A dropdown at the top lets you switch to any of the other auto-converted (unverified)
  reports produced by the migration pipeline, read live from
  `HCMv3.ReportMigrator/out/mrt-all/*.mrt` (regenerated by running that pipeline; not
  checked into git).

## How to run

```
dotnet run --project aspnet-core/tools/HCMv3.ReportDesigner
```

Then open the URL printed in the console (e.g. `http://localhost:5299/`) in a browser.
The designer loads the payslip report by default; use the dropdown to open another
report from `out/mrt-all` if that folder has been populated.

If Stimulsoft's trial license banner/watermark appears in the designer, that's expected
- this project uses the same trial as the rest of the migration tooling.

## Notes

- Never touch `aspnet-core/src/` or `angular/` from this tool - it's completely separate.
- `bin/` and `obj/` are gitignored locally in this folder (see `.gitignore` here).
