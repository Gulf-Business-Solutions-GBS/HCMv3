# AI Assistant — how to switch it off or remove it

Built on branch `feat/ai-agent` (worktree `C:\GBS\HCM\HCMv3-ai-agent`) so it can be dropped cleanly.

## 1. Switch it off without touching code

Take away the **Ess.AiAgent** permission ("AI Assistant" under Employee Self Service) from every role and user.
The menu item disappears and every API call is refused. The data stays where it is.

## 2. Remove it before it has been merged

Nothing else in the solution knows about it yet, so delete the worktree and the branch:

```bash
git worktree remove C:/GBS/HCM/HCMv3-ai-agent
git branch -D feat/ai-agent
```

## 3. Remove it after it has been merged

It is merged as **one commit**. Undo the database first, while the migration class still exists, then the code.

1. **Database** — roll back to the migration just before `Added_AiAgent_Conversations`
   (run from `aspnet-core/src/HCMv3.EntityFrameworkCore`):
   ```bash
   dotnet ef database update <name of the migration before Added_AiAgent_Conversations> --startup-project ../HCMv3.Web.Host
   ```
   This drops `AiConversations`, `AiMessages` and `AiPendingActions` and nothing else.
   If another migration has been added on top since, drop the three tables by hand instead and delete the
   migration's row from `__EFMigrationsHistory`.
2. **Code** — `git revert -m 1 <merge commit>`.
3. **Proxies** — regenerate the Angular service proxies (the AI proxy classes go away), then restart Angular.
4. **Model** — optionally uninstall Ollama and delete the model: `ollama rm qwen3:4b`.

New, self-contained:

| Layer | Path |
|---|---|

| EntityFrameworkCore | migration `Added_AiAgent_Conversations` |

Small additions to shared files, each marked `AI assistant` / `feat/ai-agent`:

- `HCMv3.Core.Shared/Authorization/AppPermissions.cs` — `Ess_AiAgent`
- `HCMv3.Core/Authorization/AppAuthorizationProvider.cs` — one registration line
- `HCMv3.Core/Localization/HCMv3/HCMv3.xml` and `HCMv3-ar.xml` — one block of keys
- `HCMv3.EntityFrameworkCore/EntityFrameworkCore/HCMv3DbContext.cs` — 3 DbSets, 3 configuration blocks

No NuGet or npm packages were added.

## Settings (all optional)

`appsettings.json` → `AiAgent` section. With no section the assistant uses Ollama on the same machine.

| Key | Default | Notes |
|---|---|---|
| `BaseUrl` | `http://localhost:11434/v1` | Any OpenAI-compatible endpoint |
| `Model` | `qwen3:4b` | e.g. `qwen3:32b` on a GPU server |
| `ApiKey` | *(none)* | Keep out of source control: `AiAgent__ApiKey` environment variable |
| `TimeoutSeconds` | `300` | CPU-only hosts are slow |
| `Temperature` | `0.2` | |
| `DisableThinking` | `true` | Qwen3 `/no_think` switch |
