## Overview

A reference sheet of what each grade is entitled to -- tickets, allowances, leave, salary range -- held as free text.

Not read at present: payroll does not use these entries, and nothing turns them into pay. They are kept for reference only.

## Grade {#TempBenefitType.Grade}
<!-- alias: loc:Grade, dom:TempBenefitType_Grade -->

**What it is.** The grade these entitlements are for.

**Example.** Grade 5

**Why it matters.** Each grade can appear only once.

**Rules.** Required. Maximum 256 characters.
