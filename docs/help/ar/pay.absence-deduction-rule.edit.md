## Overview

سلّم مسمّى لتخفيض أجر الإجازة المرضية كلما تراكمت الأيام المرضية خلال الدورة. وخطواته هي تفاصيله، ويُربط السلّم باستحقاق الإجازة المرضية للمجموعة الفرعية.
