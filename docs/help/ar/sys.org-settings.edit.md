## Overview

ميزات إدارة التنظيم المفعّلة.

لا يُقرأ أي من هذه الإعدادات حالياً: فالميزات التي تتحكم فيها لم تُنقل من النظام السابق، لذا لا أثر لتغييرها.

لكل شركة سجل إعدادات واحد، ولا يمكن حذفه.

## EnablePostingGroup {#ManageOrgSettings.EnablePostingGroup}
<!-- alias: loc:EnablePostingGroup, dom:OrgSettings_EnablePostingGroup -->

**ما هو.** ما إذا كانت مجموعات الترحيل مستخدمة.

**لماذا يهم.** لا يُقرأ حالياً -- تغييره لا أثر له.

**القواعد.** نعم أو لا.
