## Overview

أنواع الإجراءات الشخصية التي تُسجَّل على الموظفين -- التعيين، والنقل، والترقية، والفصل، ونحو ذلك. ويسمّي كل إجراء للموظف واحداً منها.

خانات المتطلبات في هذا النموذج محفوظة لكنها غير مطبّقة حالياً: فحفظ إجراء للموظف لا يتحقق منها.

## ReqOrgAssignment {#PersonalAction.ReqOrgAssignment}
<!-- alias: loc:ReqOrgAssignment, dom:PersonalAction_ReqOrgAssignment -->

**ما هو.** كان المقصود منه اشتراط تعيين تنظيمي جديد مع الإجراء.

**لماذا يهم.** غير مطبّق حالياً.

**القواعد.** نعم أو لا.
