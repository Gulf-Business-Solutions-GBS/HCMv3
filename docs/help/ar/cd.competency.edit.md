## Overview

مهارة أو سلوك يُقيَّم الموظفون على أساسه.

## CompetencyType {#Competency.CompetencyTypeId}
<!-- alias: loc:CompetencyType, dom:Competency_CompetencyTypeId -->

**ما هو.** المجموعة التي تنتمي إليها الكفاءة.

**مثال.** أساسية

**القواعد.** إلزامي. يُختار من قائمة أنواع الكفاءات.

## Active {#Competency.Active}
<!-- alias: loc:Active, dom:Competency_Active -->

**ما هو.** ما إذا كانت الكفاءة مستخدمة.

**لماذا يهم.** لا يُقرأ حالياً: يمكن اختيار الكفاءات غير النشطة.

**القواعد.** نعم أو لا.
